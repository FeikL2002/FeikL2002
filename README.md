## A guide for visitors

Each repository explains its purpose, source layout, setup requirements, and current development status. The Software Lab catalog separates applications by project so you can follow one idea without sorting through unrelated files.

Some projects are experiments or platform-specific prototypes. Their READMEs identify which features are implemented, which checks were run, and which integrations still require configuration. Network observations, demonstration data, and historical lab evidence are labeled according to what they actually show.
